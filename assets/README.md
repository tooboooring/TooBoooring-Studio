# Assets Folder

This folder contains icon images used throughout the Video Production App.

## Required Icons

Place the following PNG icons in this folder (all should be PNG format):

### Core Icons (20x20px recommended)
- `folder.png` - Folder icon for file selection
- `save.png` - Save icon for saving files/settings
- `scissors.png` - Scissors icon for cutting/processing
- `play.png` - Play icon for video playback
- `pause.png` - Pause icon for video playback
- `search.png` - Search icon for analysis/search functions
- `delete.png` - Delete icon for removing items
- `preview.png` - Preview icon for video preview
- `reset.png` - Reset icon for resetting to defaults

### Icon Specifications
- **Format**: PNG with transparency
- **Size**: 20x20px or 24x24px (will be scaled automatically)
- **Style**: Simple, clean icons that work on dark backgrounds
- **Color**: White or light gray icons work best with the dark theme

## Icon Sources

You can download icons from:
- [Flaticon](https://www.flaticon.com/)
- [Icons8](https://icons8.com/)
- [Material Icons](https://fonts.google.com/icons)
- [Feather Icons](https://feathericons.com/)
- [Heroicons](https://heroicons.com/)

## Notes

- If an icon is not found, the app will fall back to emoji/text alternatives
- Icons are cached after first load for better performance
- All icons should have transparent backgrounds
